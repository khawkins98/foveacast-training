Saliency Model Comparison — Does fine-tuning on UI content help?

Same MSI-Net architecture, two different weight sets. Stock was trained on SALICON (natural photographs). Fine-tuned was trained on UEyes (1,980 UI screenshots with real eye-tracking). The difference is purely which weights are loaded — not a runtime parameter. Foveacast ships one .onnx and that's the model.

Quantitative result (108-image held-out UEyes test split):

FP32 vs FP16 ONNX — does quantisation affect quality?

The release artefact can ship as fp32 (106 MB) or fp16 (57 MB). FP16 halves the conv weights to 16-bit floats. Max pixel diff across the comparison set is 0.78% — less than one shade of gray on a 256-level scale. If you can't tell these apart, ship fp16.
