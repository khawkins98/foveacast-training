Phase 7 — Does the fine-tuned model hit UI targets?

Same MSI-Net architecture, two different weight sets. Stock was trained on SALICON (natural photographs). Fine-tuned was trained on UEyes (1,980 UI screenshots with real eye-tracking). The difference is purely which weights are loaded — not a runtime parameter. Foveacast ships one .onnx and that's the model.
